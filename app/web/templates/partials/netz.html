Wie das Netz zu lesen ist

Die Achsen

Acht Speichen, eine je kamera-weiter Erkennungseinstellung — Analyse-Intervall, Bewegungs-Vortrigger, Nachlauf, Gnadenfrist, IoU-Schwelle, ROI-Modus, Wildtier-Empfindlichkeit, Min.-Strecke. Das läuft alles VOR jeder Klassifikation, also kamera-weit statt pro Klasse — deswegen ist das hier kein Radar aus Person/Katze/Vogel.

Was der Radius bedeutet

Innen ist immer der sparsamere/vorsichtigere Wert dieser einen Einstellung, außen der aktivere/empfindlichere — die genaue Bedeutung ist pro Achse verschieden (kurzes Analyse-Intervall ist z. B. „außen", während eine hohe IoU-Schwelle „innen" ist). Auf den Achsennamen tippen zeigt die Kurz-Erklärung dieser einen Speiche.

Ziehen

Eine Ecke lässt sich direkt verschieben, fein abgestuft statt in Stufen (bei ROI-Modus und Nachlauf rastet sie auf den vorhandenen Stufen ein). Beim Loslassen wird der Wert vorgemerkt; erst „Übernehmen" schreibt ihn, „Verwerfen" nimmt alles seit dem letzten Speichern zurück. Langes Halten setzt eine einzelne Achse auf Werk zurück.

Der Farbring — Werk oder von Hand

Werk — Startwert, noch nie berührt manuell — von dir gezogen

Diese acht Werte lernen nicht automatisch aus Telegram-Antworten — dafür gibt es keine Rückmeldung, die sagt „das Analyse-Intervall war falsch". Sie bleiben, wie du sie setzt.

Pro-Klasse-Konfidenz — jetzt eine eigene Nebenansicht

Wie sicher sich das System bei Person, Katze, Vogel & Co. sein muss, bevor es dich erreicht, lebt jetzt in der Falte „Pro-Klasse-Konfidenz" darunter — unverändert im Mechanismus: ein Radius je Klasse, geformt von deinen Richtig/Falsch/ Etwas anderes-Antworten in Telegram, mit Farbring (Werk/manuell/automatisch) und Füllung/Größe als Beleg-Anzeige. Jede Antwort landet weiterhin im Verlauf-Tab.

Die eine feste Grenze

Auf einer Sicherheitskamera darf die Automatik die Konfidenz-Achse „Person" nie über eine feste Grenze hinaus lockern — eine verpasste Person wäre der teuerste Fehler, den dieses System machen kann. Ein manueller Zug über diese Grenze bleibt möglich, aber nur mit ausdrücklicher Bestätigung.
