Wie das Netz zu lesen ist

Die Achsen

Ein Speiche pro Klasse, die diese Kamera meldet — Person, Katze, Vogel, Eichhörnchen, Hund, Auto, dazu Fuchs / Igel / Marder / Reh, wenn die Wildtier-Kaskade läuft. Eine Klasse ohne Speiche wird auf dieser Kamera gar nicht erst gesucht.

Was der Radius bedeutet

innen · streng — meldet nur Sicheres außen · empfindlich — meldet mehr

Eine Ecke näher zur Mitte heißt: diese Klasse muss sich sicherer sein, bevor sie dich erreicht — weniger Meldungen, aber auch seltener eine falsche. Weiter außen heißt: schon ein unsicherer Treffer wird gemeldet.

Ziehen

Eine Ecke lässt sich direkt verschieben, fein abgestuft statt in Stufen. Beim Ziehen erscheint eine Vorschau; erst „Übernehmen" schreibt den Wert, „Verwerfen" nimmt alles seit dem letzten Speichern zurück.

Der Farbring — wer zuletzt bewegt hat

Werk — Startwert, noch nie berührt manuell — von dir gezogen automatisch — von deinen Telegram-Antworten verschoben

Füllung & Größe — wie viel Beleg dahintersteht

Eine hohle, kleine Ecke auf einer blassen Speiche heißt: noch keine Rückmeldung zu dieser Klasse — der Wert ist ein Startwert, keine Einschätzung. Je mehr deiner Telegram-Antworten dazu vorliegen, desto voller und größer wird sie, bis zu einem weißen Ring, sobald genug Fälle beurteilt sind, um dem Wert wirklich zu vertrauen.

Wie es sich von selbst verbessert

Zu jeder Erkennung fragt Telegram: Richtig, Falsch oder Etwas anderes. Jede Antwort landet im Verlauf-Tab — mit dem Bild vom Moment der Frage, den Werten, die zu dem Zeitpunkt galten, und was sich dadurch geändert hat. Änderte sich nichts, steht dort ehrlich „bestätigt, keine Änderung".

Die eine feste Grenze

Auf einer Sicherheitskamera darf die Automatik die Achse „Person" nie über eine feste Grenze hinaus lockern — eine verpasste Person wäre der teuerste Fehler, den dieses System machen kann. Ein manueller Zug über diese Grenze bleibt möglich, aber nur mit ausdrücklicher Bestätigung.
