{# ── Shared maintenance-panel macro ───────────────────────────────────────── Renders the outer accordion shell + "Sonderaktionen" sub-block, plus — for the one caller that asks for it — the whole Aufbewahrung form. Each control stamps ``data-section``/``data-field`` (its settings.json coordinates) so ``js/maintenance/`` builds the save payload by walking the DOM, per CLAUDE.md's rule against collecting from cached JS state. Adding a category is one entry in the catalog and nothing here.
